# Reflection (write this yourself, without AI)

Aim for about half a page. Use your actual experience, not generic claims.

- What did I get wrong about the problem at the start?
- What did the canteen staff member say that changed my plan?
- What feature would I cut if I had only one more hour, and why?
- Where did AI help me?
- Where did AI waste time or suggest something unsuitable?
- What should the tool not be trusted for?
- What would I improve after observing the canteen use it?
